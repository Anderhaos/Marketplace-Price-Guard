# Goal NoSale SaaS: закрытие аудита
Дата: 2026-10-23. Scope: только SaaS /srv/mpnosale-saas/source/saas; legacy не менять.

## Приёмка
- Только активные подписчики занимают слоты фоновой очереди WB.
- Новые команды не стираются старой проверкой; ожидающие подтверждения WB операции не поглощают последующие команды.
- Массовые изменения идут пакетами не более 1000 товаров.
- GET главного экрана не выполняет сетевых запросов; воркер переживает сбой цикла.
- TLS банка проходит проверку официальными доверенными сертификатами без отключения верификации.
- Серверная сверка статуса оплаты и возврата по API Точки без доверия браузерному редиректу.
- Прогрессивная защита PIN, подтверждение критического ограничения скидок до 0%.
- DB-операции товаров пакетированы; для HTTPS включён HSTS.
- Полная регрессия, проверки миграций, Git SHA, работающие сервисы и публичные URL.

## Коммерческий блокер
Не включать настоящий эквайринг без утверждённого тарифа, отдельного мерчанта и API/JWK, проверенной фискализации по 54-ФЗ и разрешённого реального тестового платежа/возврата. Эти данные не подменять данными MiniBook.
