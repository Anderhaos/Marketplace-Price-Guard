2. Состав персональных данных и других сведений

2.1. Аккаунт продавца и безопасность

  • Email, идентификатор учётной записи и настройки пользователя, включая часовой пояс и уведомления.
  • Защищённые значения PIN, одноразовых кодов и сессий, сведения о попытках входа, IP-адресе, устройстве и времени доступа, необходимые для безопасности.
  • Согласие на использование AI-резюме и его отзыв, подписки на Web Push при добровольном подключении.

2.2. Подключённые магазины Wildberries

  • Идентификаторы магазина, артикулы, цены, скидки, зафиксированные ограничения и результаты проверок/попыток исправлений.
  • API-токены Wildberries, которые продавец передаёт для разрешённых им действий; такие токены защищаются серверными механизмами и не публикуются в интерфейсе и открытых журналах.
  • Данные участия в акциях, остатки/доступные показатели и финансовая отчётность Wildberries — только при соответствующих разрешениях API и включении функции.

2.3. Подписка и платежи

  • Выбранный тариф, даты действия доступа, стоимость, платёжный статус и технические идентификаторы операций.
  • Для работы с банком/фискальным провайдером — необходимый минимум контактных данных для оплаты и электронного чека после открытия продаж.

Полный номер банковской карты и CVV/CVC NoSale не получает и не хранит.

3. Цели обработки

  • Регистрация, вход по email/PIN, восстановление доступа, безопасность и предотвращение злоупотреблений.
  • Подключение магазина по запросу продавца, мониторинг скидок WB, предоставление настроенных функций и техническая поддержка.
  • Хранение истории изменений, уведомления о событиях, создание сводок, исполнение договора и учёт действующего тарифа.
  • Обработка оплаты и фискальных документов только после подключения соответствующих сервисов.
  • Создание кратких AI-резюме по отдельному добровольному согласию пользователя в рамках включённого тарифа и лимитов.

4.2. Продавец подтверждает, что вправе передать NoSale API-токен и сведения своего магазина. Продавец не должен предоставлять данные покупателей Wildberries, работников или третьих лиц без соответствующего правового основания.

4.3. Пользователь может отозвать согласие на AI-обработку и отключить Web Push через настройки. Отзыв не отменяет хранение сведений, необходимое для исполнения закона или действующего договора.

5. Операции с данными

Оператор может выполнять сбор, запись, систематизацию, накопление, хранение, уточнение, извлечение, использование, предоставление доступа уполномоченным лицам и провайдерам, обезличивание, блокирование, удаление и уничтожение данных — в объёме, необходимом для указанных целей.

Обработка осуществляется с использованием средств автоматизации. Доступ работников и сервисных процессов ограничивается их задачами и правами.

6. Получатели и внешние сервисы

  • Wildberries — API-запросы по поручению владельца магазина в пределах выданного им токена, получение данных и разрешённые изменения скидок.
  • Поставщики инфраструктуры — размещение веб-сервиса, защищённой базы данных, резервных копий и доставка технических сообщений.
  • Почтовый сервис и Web Push — подтверждение email и доставка запрошенных пользователем уведомлений.
  • AI Platform/DeepSeek — только при наличии отдельного согласия и соответствующих прав по тарифу: минимальные факты о ценах/скидках магазина для краткого резюме, без API-токенов, PIN и данных банковских карт. Пользователь может работать без AI-резюме.
  • Банк Точка и фискальный провайдер — только после открытия платежей, в части сведений, необходимых для расчёта и выдачи чека.

При обработке через стороннюю платформу, включая возможную трансграничную передачу, оператор должен соблюдать применимые требования законодательства. Включение AI не означает автоматического согласия пользователя на любые передачи данных.

7. Сроки хранения, безопасность и удаление

7.1. Данные сохраняются в течение срока, необходимого для работы аккаунта, выполнения договора, рассмотрения обращений, технической безопасности и исполнения обязательных требований к учёту. Сроки для различных категорий могут отличаться. После утраты основания данные удаляются, блокируются либо обезличиваются в установленном порядке.

7.2. Оператор использует разграничение прав по аккаунтам и магазинам, HTTPS, меры защиты секретов, журналирование событий и резервное копирование. Ни один метод защиты не гарантирует отсутствия любых рисков.

7.3. По запросу об удалении данных оператор проверяет действующие основания хранения и удаляет сведения, для которых основания прекратились. Сведения, которые обязательно сохранять по закону, могут не удаляться до окончания соответствующего срока.
