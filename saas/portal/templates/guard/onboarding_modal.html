Подключите Wildberries

Сначала подключите API. После проверки токена откроется кабинет и начнутся 5 бесплатных дней.

  1. Откройте WB Партнёры ↗ → Профиль → Интеграции по API → Создать токен.
  2. Для облачного сервиса предпочтителен сервисный токен из каталога WB. Если он недоступен, для начальной проверки можно создать базовый во вкладке «Для интеграции вручную» (с ограниченными возможностями).
  3. Категории: Цены и скидки и Контент. Уровень: Чтение и запись. Персональный токен для облачного сервиса использовать нельзя.
  4. Скопируйте созданный токен и вставьте его ниже. Wildberries показывает его целиком только при создании.
