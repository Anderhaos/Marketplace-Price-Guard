  1. Откройте WB Партнёры ↗ → Профиль → Интеграции по API → Создать токен.
  2. Для пробного просмотра сейчас подойдёт базовый токен во вкладке «Для интеграции вручную». Для автоматической защиты требуется сервисный токен именно NoSale из каталога WB, если сервис представлен в каталоге.
  3. Категории: Цены и скидки и Контент. Для базового просмотра выберите Только чтение. Для сервисного токена с управлением скидками нужны права Чтение и запись. Персональный токен для облачного сервиса не подходит.
  4. Скопируйте созданный токен и вставьте его ниже. Wildberries показывает его целиком только при создании.
