# Marketplace Price Guard

Локальная веб-панель для продавцов маркетплейсов. Сервис подключается к API продавца, показывает товары, цены и скидки, проверяет правила антискидки и может автоматически сбрасывать опасную скидку продавца до разрешенного значения.

Сейчас полностью рабочий адаптер есть для Wildberries. Архитектура проекта уже вынесена в отдельные модули маркетплейсов, поэтому Ozon и Яндекс Маркет подключаются как следующие адаптеры без переписывания сайта.

## Что умеет

- выбор маркетплейса на странице настроек;
- ввод и локальное хранение API токена;
- дашборд товаров, цен, скидок и статусов;
- сортировка по каждому столбцу;
- ручное исправление скидки по кнопке;
- автоматический цикл проверки;
- лимит исправлений за один цикл;
- история действий по датам;
- email-уведомления при действиях и ошибках, если настроен SMTP;
- режим `READ_ONLY` для безопасного просмотра и `LIVE` для реальных изменений.

## Поддержка маркетплейсов

| Маркетплейс | Статус |
| --- | --- |
| Wildberries | Работает |
| Ozon | Каркас адаптера готов, API подключается следующим модулем |
| Яндекс Маркет | Каркас адаптера готов, API подключается следующим модулем |

## Быстрый запуск на Windows

1. Распаковать архив в обычную папку.
2. Запустить `run.bat` двойным кликом.
3. Если Python не установлен, запустить `install_python_and_run.bat`.
4. Открыть `http://127.0.0.1:8001`.
5. Перейти в раздел `Маркетплейс и автоцикл`.
6. Выбрать маркетплейс и вставить API токен.
7. Настроить автоцикл, интервал проверки и лимит исправлений.

Черное окно закрывать нельзя: пока оно открыто, локальный сайт работает.

## Настройки `.env`

```env
APP_MODE=LIVE
LIVE_MAX_FIXES=100
AUTO_CHECK_ENABLED=1
CHECK_INTERVAL_SECONDS=300
ENCRYPTION_KEY=change_me_to_random_long_string
DATABASE_PATH=data/app.db
```

`APP_MODE=READ_ONLY` безопасно читает данные и ничего не меняет.
`APP_MODE=LIVE` включает реальные изменения через API выбранного маркетплейса.

## Что не публиковать

- `.env`
- `data/app.db`
- `data/actions.log`
- `data/products.json`, если там реальные товары клиента
- `app/__pycache__/`
- локальные zip-архивы

## Архитектура

Маркетплейсы лежат в `app/marketplaces/`.

```text
app/marketplaces/
  base.py
  factory.py
  wildberries.py
  stubs.py
```

Сайт работает не напрямую с Wildberries, а через общий клиент маркетплейса. Поэтому проект можно развивать как универсальный продукт: добавить `ozon.py`, `yandex_market.py` и подключить их в `factory.py`.

## Для работы 24/7

Локальная версия работает только пока открыт компьютер и запущен `run.bat`. Для постоянной работы проект нужно поставить на VPS/сервер, запустить как сервис и закрыть HTTPS через Nginx или Caddy.
